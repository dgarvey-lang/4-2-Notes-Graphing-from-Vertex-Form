# 4-2 Notes Graphing from Vertex Form

An interactive, step-by-step lesson on graphing y = a(x − h)² + k using the pattern (over 1 up 1, over 2 up 4, over 3 up 9).

**Student link:** https://dgarvey-lang.github.io/4-2-Notes-Graphing-from-Vertex-Form/

You can also open `4-2 Notes Graphing from Vertex Form.html` directly in a browser.

Steps:
1. The pattern of y = x²
2. Does shifting change the pattern?
3. What if it opens down?
4. What does **a** do? (a is the y-multiplier)
5. How to graph from vertex form
6. Practice: graph 6 equations by plotting points
7. Notes checklist
